# 🎬 Python Movie Recommender

A content-based movie recommender system built with Python.

## How It Works
- Uses the MovieLens dataset (9,700+ movies, 100,000+ ratings)
- Recommends movies based on genre similarity and average ratings
- Cosine similarity algorithm to find closest matches

## Technologies Used
- Python
- Pandas
- Scikit-learn
- MovieLens Dataset

## How To Run
1. Clone the repo
2. Install dependencies: `pip install -r requirements.txt`
3. Run: `python recommender.py`
4. Type any movie name and get 5 recommendations!

## Example
Enter a movie name: Toy Story

Monsters, Inc. (2001) ⭐ 3.87
Toy Story 2 (1999) ⭐ 3.86
